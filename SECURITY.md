# Security Policy

## Supported versions

After public release, the latest minor version and the immediately previous minor version are supported for 90 days after supersession. Before public release, only the current main branch receives fixes.

## Reporting

Use GitHub Private Vulnerability Reporting for this repository. Do not open a public issue for suspected token disclosure, cache exposure, query-limit bypass, release-integrity, signature, or provenance failures.

Reports are acknowledged within five business days. Token exposure and release-integrity failures are treated as urgent. Include reproduction steps, affected versions, impact, and any suggested mitigation. Coordinated advisories and patched releases will be published when users must take action.

Never include a real STRATZ token, private player data, cache database, or fetched restricted schema/constants in a report.
